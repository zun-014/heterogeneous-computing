| **常用术语**      |              |                                |
| ----------------- | ------------ | ------------------------------ |
| **Conv**          | 卷积         | 滑动窗口提取局部特征           |
| **MatMul**        | 矩阵乘法     | 全连接、注意力的核心计算       |
| **Transpose**     | 转置         | 行列互换，如 Q×K^T             |
| **Reshape**       | 改变形状     | 元素不变，只改排列形状         |
| **Flatten**       | 展平         | 多维张量变一维                 |
| **Concat**        | 拼接         | 多个张量沿某维度合并           |
| **Add**           | 加法         | 逐元素相加，残差连接           |
| **ReLU**          | 激活函数     | 负数变 0，正数不变             |
| **Sigmoid**       | 激活函数     | 压缩到 0~1                     |
| **Softmax**       | 归一化       | 多分类输出概率                 |
| **MaxPool**       | 最大池化     | 取窗口最大值，降维             |
| **AvgPool**       | 平均池化     | 取窗口平均值                   |
| **GlobalAvgPool** | 全局平均池化 | 整张图取平均，压成一个数       |
| **BatchNorm**     | 批归一化     | 按批次归一化，加速训练         |
| **LayerNorm**     | 层归一化     | 按特征归一化，Transformer 常用 |
| **Dropout**       | 随机丢弃     | 训练时随机置零，防过拟合       |
| **FC / Dense**    | 全连接层     | 每个输入连所有输出             |
| **NMS**           | 非极大值抑制 | 目标检测后处理，去重复框       |
| **Tensor**        | 张量         | 模型中的数据单位（多维数组）   |
| **Operator / Op** | 算子         | 计算图中的一个计算步骤         |
| **Quantization**  | 量化         | FP32→INT8，加速推理            |
